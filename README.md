# 老周的铁匠铺

三天限时订单 Demo。玩家在同一个铺面里领刀坯、安排工位、搬运半成品，再按时交付。高级订单的工序更多、分数更高。还有别的订单在等时，可以决定留下来精准落锤，或先把下一把刀送上工位。

## 运行

需要 Node.js 22.12+，或 Node.js 20.19+。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。用 Chrome 或 Edge 打开游戏。

```powershell
npm run check
npm run shot -- play
node tests/browser-smoke.mjs
npm run pack
node tests/browser-smoke.mjs --offline
```

`npm run pack` 生成 `release/index.html`。双击即可离线游玩。发布包、构建目录、依赖和测试截图由 Git 忽略。

## 怎么玩

- **WASD 或方向键**移动。到工位旁时，用**空格**领料、放下、取回或交付。
- **1～3** 选订单。卡片编号和刀坯标记对应。每次只能携带一把刀，工位加工完成后仍须取走刀坯。
- 在铁砧旁空手按 **F** 落锤。指针进入绿区时落锤会得到精准加分。一次锻打取第一次落锤。
- **Esc** 或右下角「暂停」打开面板，冻结订单和加工计时。音乐与音效可以分别调整，音量保存在当前浏览器中。
- 开始后有一张不限时练习单。按 **Enter** 可以开始第一天。营业结束按当日分结算，三天的目标为 **100／170／260**。未达标可以重试当天。

完整规则见 [游戏玩法.md](游戏玩法.md)。
